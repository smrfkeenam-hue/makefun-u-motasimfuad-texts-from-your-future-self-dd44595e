> Future you here. The plant died. The fake one. You killed a plastic plant. Start there.

## Competition

[Texts From Your Future Self](https://make.fun/bounty/u-motasimfuad-texts-from-your-future-self-dd44595e) on make.fun — write one funny text message your future self sends you, under 200 characters.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```

This writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` — exactly one line, no trailing newline.
